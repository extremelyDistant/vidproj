# vidproj
> 视频剪辑项目脚手架工具，对标 `uv` 的项目初始化思路，一键创建标准化素材目录树 + 批量媒体文件重命名。
> 适合短视频、宣传片、实拍项目统一管理工程/原始素材/成片，解决文件夹乱序、文件名不规范问题。

## ✨ 功能特性
1. 一键生成带数字前缀的完整项目目录，天然防止资源管理器乱序
2. 严格遵循自定义规范：
   - 项目根目录：`日期_项目名称`
   - 原始素材命名模板：`时间_机型_机位`
   - 成片导出命名模板：`时间_片名_分辨率_编码_格式_导出人_备注_版本`
3. 交互式批量重命名视频、音频素材
4. 跨平台：Windows / macOS

## 🚀 快速安装
### 方式1：使用 uv 安装（推荐！贴合项目设计初衷）
```bash
# 克隆仓库
git clone https://github.com/extremelyDistant/vidproj.git
cd vidproj

# uv 创建虚拟环境并安装
uv venv
uv pip install .
### 方式 2：原生 pip
git clone https://github.com/extremelyDistant/vidproj.git
cd vidproj
pip install .
## 📖 使用教程

### 1. 创建新项目脚手架
vidproj new 20261001_新品宣传短片
自动生成全套文件夹树。

### 2. 批量重命名原始拍摄素材

进入 `02_原始素材/03_原素材/01_时间_机型_机位`
vidproj rename_raw
模板：`时间_机型_机位`

###3. 批量重命名成片
进入 `06_导出/01_成片`
模板：`时间_机型_机位`

###3. 批量重命名成片
进入 `06_导出/01_成片`
模板：`时间_片名_分辨率_编码_格式_导出人_备注_版本`
